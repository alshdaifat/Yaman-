## 🎯 What is YamanAi?

YamanAi is an intelligent, offline-capable web application that helps electrical engineers create optimized AI prompts for their daily tasks. It features:

- **Smart Prompt Generator** with evidence-based quality criteria
- **AI & Model Recommendations** for different task types
- **Trilingual Interface** (German, English, Arabic)
- **100% Offline Functionality** (no external dependencies)
- **Direct Links** to AI tools and GitHub resources
- **Educational Content** explaining how AI works

## 🚀 Quick Start

1. Open `yaman-ai-guide-trilingual.html` in any modern browser
2. Select your preferred language (🇩🇪 🇬🇧 🇸🇦)
3. Describe your task in the prompt generator
4. Get an optimized AI prompt with recommendations
5. Copy and use in your preferred AI tool!

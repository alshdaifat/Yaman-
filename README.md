# Diggai - Medical Technology Website

Professional single-page website for Diggai, a medical technology company specializing in medical devices, IT solutions, and automation for medical practices and clinics.

## 🌐 Live Demo

Open `index.html` in your browser to view the website.

## 📋 Features

### Core Sections
- **Hero Section**: Compelling introduction with call-to-action buttons
- **Services**: Medical technology, IT solutions, and automation offerings
- **Solutions**: Industry-specific solutions for different practice types
- **Benefits**: 6 key advantages of choosing Diggai
- **About Us**: Company information with statistics and certifications
- **Contact**: Multi-channel contact options with functional form
- **Footer**: Comprehensive navigation and legal information

### Interactive Features
- ✅ Smooth scrolling navigation
- ✅ Responsive mobile menu
- ✅ Active navigation highlighting
- ✅ Scroll-triggered animations
- ✅ Contact form with validation
- ✅ Back-to-top button
- ✅ Animated statistics counter

### Technical Highlights
- 📱 Fully responsive (mobile, tablet, desktop)
- ♿ Accessible (ARIA labels, semantic HTML)
- 🎨 Modern, professional design
- 🚀 Fast loading (no dependencies)
- 🔒 GDPR/DSGVO compliant
- 🌍 German language content

## 🛠️ Technologies

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JS for interactivity
- **Google Fonts**: Inter font family

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required!

## 🔧 Customization

### Update Company Information
Edit the contact details in `index.html`:
- Phone number
- Email addresses
- Physical address

### Modify Colors
Update CSS variables in `styles.css`:
```css
:root {
    --primary-color: #0066CC;
    --secondary-color: #00B8A9;
    /* ... */
}
```

### Change Content
All text content is in `index.html` and can be modified directly.
